## Installation

1. Download the installer and close Sticker Master if it is already running.
2. Run the installer and follow the on-screen instructions.
3. Start Sticker Master and follow the activation or trial instructions in the app.

Trial users can preview supported designs. Printing and PDF export require an active paid license.
